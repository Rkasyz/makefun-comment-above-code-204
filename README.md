One funny, painfully honest line imagining the comment a developer left above fragile production code.

## Entry

```c
// DO NOT TOUCH. This works by accident, fear, and one developer's sheer spite. If you refactor it, the tests pass and production dies. I warned you. I am that developer.
```

The comment warns the next developer that the code below only works by accident — refactor it and the tests still pass while production dies. The final reveal, "I am that developer", is the punchline: the author is still here, still warning people, still afraid to touch it.

## How it works

`main.py` writes the single line above to `$MAKEFUN_OUTPUT_DIR/entry.txt` as UTF-8 with no trailing newline. The line is 170 characters, inside the competition's 1–200 character gate.
